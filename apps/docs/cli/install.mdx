The Tracing CLI is currently distributed as source. Its workspace package and
binaries have not been published to npm, Homebrew or GitHub Releases.

Use Node.js 24 and the pnpm version declared in the repository's `packageManager`:

```bash
git clone https://github.com/Go-Figure-App/tracing.git
cd tracing
pnpm install --frozen-lockfile
pnpm --filter @tracing/cli build
node packages/cli/dist/tracing.mjs --help
```

The command examples in these docs use `tracing`. Substitute
`node /absolute/path/to/tracing/packages/cli/dist/tracing.mjs`, or define a shell
function pointing to that file. For example, after replacing the path:

```bash
tracing() { node /absolute/path/to/tracing/packages/cli/dist/tracing.mjs "$@"; }
tracing login --api-url https://tracing.gofigureapp.io
```

Run `tracing login --help` for server and API-key options. Existing Kaneo logins
and repository settings remain supported. New repository settings use
`.tracing.json`; `TRACING_*` environment variables take precedence over legacy
`KANEO_*` aliases.

## Update

Check out the reviewed commit you want to run, install its locked dependencies,
and rebuild. Keep your current credentials; rebuilding does not remove them.

## Uninstall

Remove the shell function or launcher you created. Run `tracing logout` to remove
the selected login before removing the build if you also want to sign out.
