The Tracing CLI works with self-hosted instances, shows styled terminal output,
and prints JSON for scripts and agents. [Build it from source](/cli/install)
before using the commands below; Tracing packages and binaries are not yet
published to a package registry.

## Quick start

```bash
tracing login --api-url https://tracing.gofigureapp.io
tracing
```

See [Sign in](/cli/sign-in) for server URLs and API keys.

## Everyday commands

```bash
tracing workspace list
tracing workspace use            # pick the default workspace
tracing project list
tracing task list -p KAN         # tasks grouped by column
tracing task list -p KAN --mine --open
tracing task mine                # your open tasks, soonest due first
tracing task view KAN-12
tracing task create "Fix login redirect" -p KAN --priority high --due tomorrow
tracing task status KAN-12 done
tracing task assign KAN-12 me
tracing comment add KAN-12 "Shipped in v2.35"
tracing time start KAN-12
tracing time stop
tracing task open KAN-12
tracing search "login redirect"
```

Tasks are addressed by their ticket ID, such as `KAN-12`, or by their ID. If a ticket ID exists in more than one of your workspaces, pass `-w` to choose one.

When a workspace, project or column is missing and you are in a terminal, the CLI shows a searchable picker. In scripts it stops with an error that names the flag to pass.

Every command has `--help`, and the [command reference](/cli/reference) lists every argument and flag. Print a shell completion script with `tracing --completions zsh` (or `bash`, `fish`, `sh`).
