---
title: Upstream drim compatibility
description: Use the source deployment path for Tracing.
---

The upstream [drim project](https://github.com/usekaneo/drim) deploys Kaneo.
Its upstream releases do not distribute this Tracing fork. Use the
[Tracing source Compose setup](/core/installation/docker-compose) for a new
installation or [the bundled-container migration](/core/installation/migration)
for an existing instance. Preserve the database volume, credentials and
`AUTH_SECRET` when moving an existing deployment.
