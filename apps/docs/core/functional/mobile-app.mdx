Tracing's iOS and Android source is in the [repository](https://github.com/Go-Figure-App/tracing/tree/main/apps/mobile). This fork has no published App Store listing. Build and distribute it through your own Expo account; the source build uses the `io.gofigureapp.tracing` application identifier.

The app includes boards, task details, My tasks, inbox and activity, plus triage, project plans, milestones, initiatives, roadmap, cycles, insights and saved views. Descriptions can be edited inline.

## Sign in

The Go Figure build connects to `https://tracing.gofigureapp.io`. Server selection and the self-hosted purchase flow have been removed. For local simulator testing only, the operator can set `GOFIGURE_LOCAL_SERVER_URL` before starting the build.

- Sign in using the methods enabled on the instance.
- **Continue in browser** opens device authorization on the Tracing website.
- **Use an API key** accepts a key created on the web under **Settings → Account → API keys**.
- **Create account** appears only when registration is open on the instance.

## Upgrade the server before the app

The app uses `tracing-mobile` for device authorization. Upgrade the server to a build whose default allowlist includes that ID before distributing the app. On older supported servers, explicitly add `tracing-mobile` to `DEVICE_AUTH_CLIENT_IDS`, preserving the other client IDs still in use, and restart the server. An unset allowlist on an older server can reject the updated app. See [upgrade compatibility](/core/operations/upgrades#mobile-device-sign-in-compatibility) and [environment variables](/core/installation/environment-variables).

## Delete your account

Open **Account** from your avatar, then select **Delete account** under **Danger zone**. Type your email address to confirm. If you signed in a while ago, enter your password, or sign out and back in first.

Deleting your account in the app works the same as on the web. See [what happens to your data](/core/functional/manage-your-account#what-happens-to-your-data).
